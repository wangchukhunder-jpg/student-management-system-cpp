# Student Management System in C++

A console-based Student Management System developed using C++. This project allows users to manage student records efficiently using Object-Oriented Programming concepts and file handling.

## Features
- Add Student
- View Students
- Search Student
- Update Student
- Delete Student
- Save Data to File
- Load Data from File

## Concepts Used
- Object-Oriented Programming (OOP)
- STL Vectors
- File Handling
- Searching Algorithms
- Functions and Loops

## Tech Stack
- C++
- VS Code

## Future Improvements
- Admin Login System
- GUI Interface
- Database Integration
- Sorting and Filtering
