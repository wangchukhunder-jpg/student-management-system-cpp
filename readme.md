# Student Management System in C++

A console-based Student Management System developed using C++. This project helps manage student records efficiently using Object-Oriented Programming concepts, STL vectors, searching algorithms, sorting, authentication, and file handling.

---

## Features

- Admin Login System
- Add Student
- View Students
- Search Student
- Update Student
- Delete Student
- Sort Students By ID
- Duplicate ID Prevention
- Save Data to File
- Load Data from File
- CGPA Management
- Attendance Tracking
- Marks Management

---

## Concepts Used

- Object-Oriented Programming (OOP)
- STL Vectors
- File Handling
- Searching Algorithms
- Sorting Algorithms
- Functions and Loops
- Authentication System
